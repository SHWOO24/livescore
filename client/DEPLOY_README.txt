⚠️  중요: Shared Hosting 제약사항

현재 환경에서는 다음 기능이 동작하지 않습니다:
- 실시간 채팅 (Socket.io)
- 로그인/회원가입 (백엔드 API 필요)
- 이메일 인증
- 실시간 경기 스코어 업데이트

이 기능들을 사용하려면 별도의 백엔드 서버(VPS, Railway, Render 등)가 필요합니다.

================================================================================
  배포할 파일 목록
================================================================================

다음 파일들만 public_html에 업로드하세요:

필수 파일:
  ✓ index.html
  ✓ .htaccess
  ✓ assets/ 폴더 전체 (CSS, JS 파일 포함)

업로드하지 말아야 할 것:
  ✗ node_modules/
  ✗ server/
  ✗ package.json
  ✗ tsconfig*.json
  ✗ vite.config.ts
  ✗ src/ 폴더
  ✗ 기타 개발 설정 파일들

================================================================================
  업로드 방법
================================================================================

1. FTP/SFTP 클라이언트로 cPanel에 접속
2. public_html 디렉토리로 이동
3. dist 폴더 내부의 모든 파일을 업로드
   (dist 폴더 자체가 아닌, dist 안의 내용만!)

최종 구조:
  public_html/
    ├── index.html
    ├── .htaccess
    └── assets/
        ├── index-*.css
        └── index-*.js

================================================================================
  확인 사항
================================================================================

배포 후 확인:
1. 메인 페이지가 정상 로드되는가?
2. /login, /register 등 직접 접속 시 404가 아닌가?
3. CSS/JS 파일이 정상 로드되는가?

문제 발생 시:
- .htaccess 파일이 루트에 있는지 확인
- 파일 권한 확인 (644)
- 브라우저 개발자 도구에서 오류 확인
